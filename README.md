# 心诚则灵 · 易经六爻占卜

像素古风风格的六爻铜钱**排盘**工具，纯前端实现，零依赖，打开即用。

> 本工具只负责摇钱、排本卦/变卦、画出爻线图并提示动爻数量；**不附卦辞、爻辞及卦义解说**，断卦请自行查阅传统典籍。

## 在线访问

- **在线体验**：https://foreveropen.github.io/xczl/

本地测试直接用浏览器打开 `index.html` 即可。

---

## 功能一览

- **六爻摇钱排盘**：摇三枚铜钱六次，自动排出本卦、识别动爻、推导演卦（变卦）
- **64 卦名匹配**：上下卦组合精确匹配，显示卦名与爻线图
- **动爻提示**：根据动爻数量给出传统断法位置提示（仅提示"看哪里"，不附卦辞爻辞）
- **占卜规则**：三不占（不疑/不诚/不义）+ 四戒（问须具体/一事一占/择时而问/不信不占）
- **每日限卦**：每日最多三卦，跨天自动重置
- **三月不复占**：同一问题 90 天内不可重复占卜
- **规则弹窗**：首次必弹，5 小时冷却，可勾选永久关闭
- **静心仪式**：占卜前 10 秒静心倒计时，切后台自动暂停
- **加密存储**：数据本地加密保存（XOR + UTF8 + Base64），每台设备密钥不同
- **历史记录**：分页展示，点击查看本卦+变卦
- **备份导入导出**：加密备份文件，可跨设备迁移
- **操作日志**：所有用户操作自动记录，方便排查问题

## 占卜规则

### 三不占
1. **不疑不占**：真正有疑惑才问，无事不占
2. **不诚不占**：心诚则灵，嬉戏试探不灵
3. **不义不占**：不占害人、违法、不道德之事

### 四戒
1. **问须具体**：问题要明确具体，模糊的问题得到模糊的答案
2. **一事一占**：同一问题三个月内不可重复占卜
3. **择时而问**：选一天中心最静、杂念最少的时候提问
4. **不信不占**：本就不信，不必占卜

## 技术说明

- 纯原生 HTML/CSS/JS，零依赖，零框架
- 加密方案：XOR 异或 + UTF8 字节编码 + Base64 编码
- 本地数据用"固定盐+设备UUID"加密，不同设备密钥不同
- 备份文件用统一密钥加密，可跨设备导入
- 随机数优先 `crypto.getRandomValues`，降级 `Math.random`
- 支持现代浏览器（Chrome / Edge / Safari）
- File System Access API 需要 HTTPS 环境
