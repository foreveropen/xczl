# 心诚则灵 · 易经六爻占卜

像素古风风格的六爻铜钱占卜工具，纯前端实现，零依赖，打开即用。

---

## 功能一览

- **六爻铜钱占卜**：摇三枚铜钱六次，自动排成本卦、识别动爻、推导演卦
- **64卦完整**：上下卦组合精确匹配，含卦象图和动爻断卦说明
- **占卜规则**：三不占（不疑/不诚/不义）+ 四戒（问须具体/一事一占/择时而问/不信不占）
- **每日限卦**：每日最多三卦，跨天自动重置
- **三月不复占**：同一问题90天内不可重复占卜
- **规则弹窗**：首次必弹，5小时冷却，可勾选永久关闭
- **静心仪式**：占卜前10秒静心倒计时，切后台自动暂停
- **加密存储**：数据本地加密保存（XOR + UTF8 + Base64），每台设备密钥不同
- **跨平台文件存储**：支持 File System Access API 的浏览器自动写入文件夹
- **历史记录**：分页展示，点击查看本卦+变卦详情
- **备份导入导出**：加密备份文件，可跨设备迁移
- **操作日志**：所有用户操作自动记录，方便排查问题

## 存储架构

```
                    ┌─────────────────┐
                    │   占卜数据写入   │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │   save(data)   │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
     ┌────────▼───┐  ┌─────▼─────┐  ┌────▼─────┐
     │ localStorage │  │  文件系统  │  │  备份文件  │
     │  (同步缓存)  │  │ (异步写入) │  │ (手动导出) │
     │ 设备密钥加密  │  │  用户授权  │  │ 固定密钥   │
     └─────────────┘  └───────────┘  └──────────┘
```

- **localStorage**：所有浏览器都支持，始终作为同步缓存
- **文件系统**：Chrome/Edge 桌面+安卓支持，用户授权后自动写 `gua_data.json`
- **备份文件**：用固定密钥加密，可跨设备导入导出

## 占卜规则

### 三不占
1. **不疑不占**：真正有疑惑才问，无事不占
2. **不诚不占**：心诚则灵，嬉戏试探不灵
3. **不义不占**：不占害人、违法、不道德之事

### 四戒
1. **问须具体**：问题要明确具体，模糊的问题得到模糊的答案
2. **一事一占**：同一问题三个月内不可重复占卜
3. **择时而问**：选一天中心最静、杂念最少的时候提问
4. **不信不占**：本就不信，不必占卜

### 动爻断法
| 动爻数 | 断法 |
|--------|------|
| 0个 | 以本卦卦象为断 |
| 1个 | 取本卦动爻爻辞为断 |
| 2个 | 以阴动爻为主为断 |
| 3个 | 参看本卦、变卦卦辞 |
| 4-5个 | 以变卦静爻为断 |
| 6个 | 乾坤二卦特殊参看 |

## 技术说明

- 纯原生 HTML/CSS/JS，零依赖，零框架
- 加密方案：XOR 异或 + UTF8 字节编码 + Base64 编码
- 本地数据用"固定盐+设备UUID"加密，不同设备密钥不同
- 备份文件用统一密钥加密，可跨设备导入
- 随机数优先 `crypto.getRandomValues`，降级 `Math.random`
- 支持 2023 年后现代浏览器（Chrome / Edge / Safari）
- File System Access API 需要 HTTPS 环境
